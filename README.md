# 🪨📄✂️ Stone Paper Scissors

A fun and interactive **Stone Paper Scissors** game built using HTML, CSS, and JavaScript.

The game allows the player to compete against the computer with randomly generated computer choices and keeps track of the game result.

## 🎮 Features

- 🪨 Stone, 📄 Paper and ✂️ Scissors choices
- 🤖 Play against the computer
- 🎲 Random computer choice
- 🏆 Displays the winner
- 📊 Tracks player and computer scores
- 🔄 Play again and reset functionality
- ✨ Interactive buttons and animations
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling, animations and responsive design
- **JavaScript** – Game logic and functionality
